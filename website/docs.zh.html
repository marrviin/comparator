使用文档

从安装到进阶：文本、文件夹、Git 三种对比的用法，编码识别与安全特性说明。

快速开始

从 最新版本 下载对应平台的安装包：

  • macOS — .dmg（Apple Silicon + Intel）
  • Windows — .msi / .exe
  • Linux — .AppImage / .deb

启动应用，选择两个文件即可开始第一次对比。首页保留最近打开记录，可一键重开。

安装问题排查

应用尚未进行代码签名，macOS 与 Windows 在首次启动时可能弹出一次性的安全提示。这属于 未签名应用的正常现象，按以下方式处理即可：

  • macOS —「无法打开，因为无法验证开发者」：在访达 （注意不是启动台）中右键点按应用，选择打开，再在弹窗中点 打开确认；或进入系统设置 → 隐私与安全性 ，滚动到「安全性」区域，点击仍要打开。
  • macOS —「应用已损坏，无法打开」：这是下载文件被系统标记了隔离属性 ，在终端执行一次 xattr -cr /Applications/Pure\ Compare.app ，之后即可正常打开。
  • Windows — SmartScreen 提示「已保护你的电脑」：点击 更多信息，再选择仍要运行； .msi 安装包与 .exe 均按此处理。
  • Linux — AppImage 无法启动：先赋予执行权限 chmod +x *.AppImage 再运行；.deb 安装命令： sudo dpkg -i pure-compare_*.deb。

每种提示都只需处理一次，之后可正常启动。

文本对比

  • 拖入或选择两个文件，即可并排逐行对比。
  • 双向编辑：在任意一侧直接修改并保存。
  • 语法高亮与超大文件处理由 Monaco 提供——VS Code 同款内核。

文件夹对比

  • 选择两个目录，两棵目录树递归遍历。
  • 每个条目以新增 / 修改 / 删除状态标记，一目了然。
  • 点开任意文件，进入逐行差异视图。
  • 文件类型显示真实图标，由 Material Icon Theme 驱动。

Git 对比

  • 打开仓库即可对比任意两个 ref——分支、标签、提交或工作区，两侧均可选择。
  • 变更文件列表内置重命名检测。
  • 选中文件查看逐行差异。
  • 支持单文件检出，只取回需要的那处改动。

编码与安全

  • 自动识别编码：UTF-8、UTF-16（BOM）、GBK 等。
  • 二进制文件提前识别；超大文件触发截断保护，不会卡死界面。
  • 打开期间监听外部修改，差异实时刷新。
  • 未保存修改保护，避免误丢失。
  • 忽略规则可将构建产物、依赖目录排除在文件夹对比之外。

界面

  • Chrome 风格标签页，多个对比并行打开。
  • 最近列表自动去重，支持悬停删除，按最近打开时间排序。
  • 深浅色主题一键切换；macOS 侧边栏使用原生 Vibrancy 效果。

常见问题

  • 安装提示或「应用已损坏」——见上方 安装问题排查。
  • 会收集数据吗？——不会。零遥测、无需账号，MIT 开源。
