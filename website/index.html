Positioning

A free, open-source diff tool

Beyond Compare, WinMerge, and Meld are mature, capable tools. Pure Compare takes its own angle: one lightweight, open-source app for text, folder, and Git compare.

Free & open source

MIT-licensed and free for personal and commercial use alike — no trial limits, no license keys, the full feature set from the first launch.

One app, three modes

Text, folder, and Git compare share the same workspace — tabs, history, and encoding handling included, so comparisons stay in one place.

Lightweight by design

Built with Tauri: a small download, instant startup, and low memory use, with VS Code-grade diffing from the Monaco editor.
