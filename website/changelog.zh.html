更新日志

版本发布记录与功能演进。

v0.2.0

最新版 2026-09-12

新功能

  • Git：差异左侧支持选择工作区
  • 文本 / 文件夹 / Git 对比全面采用 Chrome 风格标签页
  • 最近列表：去重、悬停删除、记录最近打开时间
  • 深色主题与一键切换，设置页新增「关于」标签
  • macOS 原生 Vibrancy 侧边栏，跟随主题色调
  • 三种对比模式的差异头部按钮统一样式

问题修复

  • 打磨对比工具栏、目录树展开与光标样式
  • 修复两侧均选择 ref 时 from..to 差异的问题

内部改进

  • 样式拆分为独立 token 文件，设置弹窗改为玻璃拟态
  • 移除 @ant-design/x，改用统一菜单皮肤与消息提示

在 GitHub 查看完整变更 →

v0.1.0

2026-09-03

首个公开版本

  • 文本、文件夹、Git 三种对比集于一身（Tauri 2 + React + Monaco）
  • 并排差异视图，语法高亮，双向编辑
  • 智能编码识别（UTF-8/16、GBK）、二进制检测与超大文件保护
  • 提供 macOS（.dmg）、Windows（.msi / .exe）、Linux（.AppImage / .deb）原生安装包
