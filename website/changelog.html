v0.4.0

Latest 2026-09-14

Breaking change

  • The app is now called Manta Compare (previously Comparator). The bundle identifier changed to com.mantacompare.app, so existing installs are treated as a separate app and their data directories reset.

Changes

  • Renamed the app across the UI, website, installer metadata, and package names
  • Recent-comparison history migrates automatically from the previous (comparator:recent) and original (pure-compare:recent) storage keys
  • Retook home screenshots and refreshed all website branding

v0.2.0

2026-09-12

Features

  • Git: pick the working tree on the left side of a diff
  • Chrome-style header tabs across text / folder / Git compare
  • Recent list: dedupe, hover-to-remove, and last-opened time
  • Dark theme with a quick switch and a new About tab in settings
  • macOS vibrancy sidebar tinted with the active theme
  • Unified diff header buttons across all three modes

Fixes

  • Polished compare toolbar, tree expansion, and cursor styles
  • Git diff from..to when both refs are picked

Internal

  • Standardized styling with split token files and a glass settings modal

v0.1.0

2026-09-03

Initial release

  • Text, folder, and Git compare in one native app (Tauri 2 + React + Monaco)
  • Side-by-side diff with syntax highlighting and two-way editing
  • Smart encoding detection (UTF-8/16, GBK), binary guard, large-file protection
  • Native installers for macOS (.dmg), Windows (.msi / .exe), and Linux (.AppImage / .deb)
