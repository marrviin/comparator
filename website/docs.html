Documentation

How to install Pure Compare and get the most out of text, folder, and Git compare.

Getting started

Download an installer from the latest release for your platform:

  • macOS — .dmg (Apple Silicon + Intel)
  • Windows — .msi / .exe
  • Linux — .AppImage / .deb

Launch the app and pick two files to run your first diff. Recent comparisons stay on the home screen and reopen in one click.

Installation issues

The installers are not code-signed yet, so macOS and Windows may show a one-time security prompt on first launch. This is expected for unsigned apps — here is how to get past each one:

  • macOS — "cannot be opened because the developer cannot be verified": right-click the app in Finder (not Launchpad) and choose Open, then confirm Open in the dialog. Or open System Settings → Privacy & Security, scroll down to the Security section, and click Open Anyway.
  • macOS — "app is damaged and can't be opened": the download was quarantined. Clear the flag once from Terminal with xattr -cr /Applications/Pure\ Compare.app, then open the app normally.
  • Windows — SmartScreen "Windows protected your PC": click More info, then Run anyway. The same applies to both the .msi installer and the .exe setup.
  • Linux — AppImage won't start: make it executable first with chmod +x *.AppImage, then run it. For the .deb: sudo dpkg -i pure-compare_*.deb.

You only need to do this once — later launches open normally.

Text compare

  • Drag in or pick two files — the diff opens side by side, line by line.
  • Two-way editing: type in either pane and save your changes.
  • Syntax highlighting and large-file handling come from the Monaco editor — the same engine behind VS Code.

Folder compare

  • Pick two directories — both trees are walked recursively.
  • Every entry is flagged added / modified / deleted at a glance.
  • Open any file to drill down into its line-by-line diff.
  • File types show real icons, powered by Material Icon Theme.

Git compare

  • Open a repository and diff any two refs — a branch, a tag, a commit, or the working tree, on either side.
  • Browse the changed-file list with rename detection built in.
  • Select a file to view its per-line diff.
  • Check out individual files when you only need one change back.

Encodings & safety

  • Automatic encoding detection: UTF-8, UTF-16 (BOM), GBK, and more.
  • Binary files are detected up front; very large files hit a truncation guard instead of freezing the UI.
  • Open files are watched — external edits refresh the diff live.
  • An unsaved-changes guard protects in-progress edits.
  • Ignore rules keep build output and dependencies out of folder comparisons.

Interface

  • Chrome-style header tabs keep several comparisons open at once.
  • The recent list dedupes entries, removes items on hover, and sorts by last opened.
  • Dark and light themes with a quick switch; the macOS sidebar uses native vibrancy.

FAQ

  • Install prompts or "damaged app" warnings — see Installation issues above.
  • Does it phone home? — No. No telemetry, no account, MIT licensed.
